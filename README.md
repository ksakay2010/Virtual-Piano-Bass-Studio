# 🎹 Virtual Piano, Bass & Loop Studio

A feature-rich, interactive web-based music studio built with vanilla JavaScript and the Web Audio API. Play multiple instruments, lay down drum beats, and layer multi-track loop performances directly inside your browser with zero external dependencies!

## ✨ Features

* **Multi-Instrument Synthesis**: Switch dynamically between **Grand Piano** (warm triangle waves), **Electric Bass** (thick sawtooth/sub-bass filter patch), and **Synth Lead**.
* **Full Keyboard Layout**: Spans two octaves (C3 to B4) with precise key alignments, mouse click/drag (glissando) support, and keyboard shortcuts.
* **Inbuilt Drum Machine**: 
  * Switchable rhythm patterns: **Rock Beat**, **Hip-Hop Groove**, **Lo-Fi Chill**, and **Techno 4/4**.
  * Adjustable tempo slider ranging from **70 to 160 BPM**.
* **Dual-Track Loop Pedal**:
  * **Track 1**: Record chord progressions or melodies, and loop them seamlessly.
  * **Track 2**: Layer basslines or lead harmonies over your first track.
* **Responsive Controls**: Includes octave shifting (-1, Standard, +1) and real-time visual feedback when keys are triggered.
